# Third-party code and licences

This file records what Founder Idea Check copied, adapted or took a design from,
and the notable licences of what it runs. For each upstream it says what was
taken, where it lives here, the licence and copyright line, the commit it was
taken at, and how it was changed.

Founder Idea Check is licensed under Apache-2.0 (`LICENSE`). The attribution
notices that Apache-2.0 section 4(d) asks to be kept are in `NOTICE`. The full
licence text and copyright line of every MIT upstream is in `LICENSES/`: each file
there is a byte-for-byte copy of the upstream `LICENSE`, so its git blob id equals
the upstream blob id given in the ledgers. Files that were copied or adapted
also carry a banner naming their upstream, licence and commit.

**There are two ledgers; read both.** This one covers the application, the compose
stack and the generated UI components. `THIRD_PARTY-research.md` covers the
research subsystem: `apps/research/`, `apps/chat/lib/research/`,
`apps/chat/lib/signals/` and `apps/chat/tools/platform/deep-research/`.

Borrowed code is **frozen**: upstream fixes never arrive on their own, so every
entry pins the commit it was taken at. To see what an upstream fixed since:

```bash
gh api "repos/OWNER/REPO/commits?path=PATH&since=YYYY-MM-DD" --jq '.[].commit.message'
```

`shadcn add` and the AI Elements generator write files with no licence or author
header, which destroys provenance at the moment of copy. Anything taken from a
registry is therefore recorded here by hand.

Apache-2.0 section 4(b) asks modified files to carry prominent change notices.
This project meets it with the modification list in `NOTICE` and the repository
history, not with a header in every file.

## Design taken, nothing copied

The shape was reimplemented against this project's own types. Their licences are
recorded because `apps/chat/lib/phases/REFERENCES.md` quotes short passages of both
verbatim (a type, a guard, a test, JSON schema excerpts), so their notices travel
with that file.

The excerpts were re-checked against `v0.4.1` on 2026-11-12. | [codename-co/devs](https://github.com/codename-co/devs) | MIT, Copyright (c) 2025 CODENAME SAS | The `Criterion.type` vocabulary (`artifact-exists`, `requirement-satisfied`, `metric-threshold`, `phase-completed`, `custom`) and the `qualityGates` shape (`enabled`, `autoRetry`, `maxRetries`), from `public/schemas/methodology.schema.json` | `apps/chat/lib/phases/types.ts` (`ExitCriterionSchema`, `GateConfigSchema`) | `ce05b2c3dce2665e00942c540406a8bf78b39a13` (2026-08-01); the schema file was last changed at `fa3bc4758147395545f37f77c666af2c25c4fa82` (2025-10-19). Where this project deliberately differs, and why, is in `REFERENCES.md`. In short:
warden's library WARNs when it cannot evaluate, and here a phase advance is the
merge with no second gate behind it, so the gate BLOCKs; and devs' `Criterion` marks
every discriminating field optional, where ours is a discriminated union on `type`.

## What this project will and will not copy

Code under permissive licences (MIT, BSD, Apache-2.0, PostgreSQL) may be copied or
adapted with its notice kept: a banner on the file, the text in `LICENSES/`, and
a row here. Copyleft code (GPL, AGPL) is not copied into this repository.
Copyleft software appears only as a separate program the user chooses to run (the
SearXNG overlay) or to install (`igraph`, through an optional extra). Code with no
licence is not copied. Where such a project offers a public API, the API may be
called: `apps/research/app/sources/arctic_shift.py` is an original client of
Arctic Shift's API and contains none of its source.
